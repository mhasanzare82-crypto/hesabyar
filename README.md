# حسابیار (Hesabyar)

اپلیکیشن فارسی مدیریت دخل‌وخرج شخصی با Flutter.

## امکانات نسخه فعلی

- داشبورد موجودی کل، درآمد و هزینه
- ثبت درآمد و هزینه با عنوان، مبلغ، حساب، تاریخ و توضیحات
- مدیریت چند حساب و صندوق با موجودی اولیه
- مشاهده فهرست تراکنش‌ها و حذف تراکنش
- گزارش درآمد، هزینه و خالص عملکرد ماه جاری و سال جاری
- ذخیره‌سازی آفلاین روی دستگاه با `shared_preferences`
- تهیه نسخه پشتیبان JSON با کپی به کلیپ‌بورد و بازیابی از متن JSON
- رابط کاربری فارسی و راست‌چین

## اجرا

1. Flutter SDK سازگار با محدودیت نسخه در `pubspec.yaml` را نصب کنید.
2. در ریشه پروژه اجرا کنید:

```bash
flutter pub get
flutter run
```

برای ساخت APK:

```bash
flutter build apk --release
```

## نکات نسخه MVP

- تاریخ‌ها در این نسخه میلادی هستند و نمایش گزارش‌ها نیز بر اساس ماه و سال میلادی دستگاه انجام می‌شود.
- واحد نمایش مبلغ در این نسخه تومان است.
- پشتیبان‌گیری به شکل متن JSON انجام می‌شود؛ متن کپی‌شده را در فایل امن نگهداری کنید.
- داده‌ها محلی هستند. حذف و نصب مجدد برنامه یا پاک‌کردن داده‌های آن ممکن است اطلاعات را از بین ببرد؛ قبل از آن پشتیبان بگیرید.
- انتقال وجه بین حساب‌ها، ویرایش تراکنش، خروجی فایل و تقویم شمسی برای نسخه‌های بعدی در نظر گرفته شده‌اند.


## دریافت پیامک در اندروید

- از تنظیمات، بخش «خواندن پیامک‌ها» را باز کنید و شماره/سرشماره‌های مجاز را دستی اضافه کنید.
- پس از اعطای مجوز اندروید و روشن‌کردن قابلیت، فقط پیامک‌های جدیدِ فرستنده‌های انتخاب‌شده دریافت می‌شوند؛ صندوق پیامک‌های قدیمی خوانده نمی‌شود.
- مبلغ، تاریخ و ساعت با الگوهای عمومی از متن پیامک استخراج می‌شوند. چون قالب پیامک بانک‌ها و سرویس‌ها متفاوت است، ممکن است بعضی پیامک‌ها نیاز به تنظیم الگوی اختصاصی داشته باشند.
- پیامک‌ها به‌صورت خودکار به درآمد یا هزینه تبدیل نمی‌شوند؛ صرفاً در فهرست پیامک‌های پردازش‌شده نمایش داده می‌شوند.
- مجوز RECEIVE_SMS حساس است و برای انتشار در Google Play ممکن است مشمول محدودیت‌های سیاست پیامک گوگل باشد.
